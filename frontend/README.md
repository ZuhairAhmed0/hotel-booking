## التشغيل محلياً

1. شغّل الخادم الخلفي لـ Laravel من مجلد مشروع:

	```powershell
	php artisan serve --host=127.0.0.1 --port=8000
	```

2. من مجلد الواجهة الأمامية، شغّل الموقع :

	```powershell
	npx serve . -l 3000
	```

3. افتح `http://localhost:3000` في المتصفح.

يتوقع الموقع أن تكون الواجهة البرمجية متاحة افتراضياً على **`http://127.0.0.1:8000/api`**، 

يرسل المتصفح الطلبات من عنوان الواجهة الأمامية (`http://localhost:3000`) إلى عنوان Laravel (`http://127.0.0.1:8000`). يجب أن يسمح إعداد CORS في Laravel بهذا العنوان. وإذا شغّلت الواجهة الأمامية على منفذ أو اسم مضيف مختلف، فأضف عنوانها الجديد إلى إعدادات CORS في Laravel أيضاً.

## تغيير عنوان الواجهة البرمجية

إذا كان Laravel يعمل على عنوان IP أو اسم مضيف أو منفذ مختلف، غيّر قيمة `window.API_BASE_URL` في الملف [api-config.js](api-config.js). مثال:

```js
window.API_BASE_URL = 'http://192.168.1.25:8000/api';
```

غيّر اسم المضيف والمنفذ إلى العنوان الذي يستطيع المتصفح الوصول إليه، وأبقِ اللاحقة `/api` إذا كانت مسارات Laravel مسجّلة ضمن ملف مسارات API. إذا تغيّر منفذ تشغيل الواجهة الأمامية فقط، فلا حاجة لتغيير عنوان API، لكن يجب السماح بعنوان الواجهة الجديد في إعدادات CORS في Laravel.
